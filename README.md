# java-explore-with-me-plus
Template repository for ExploreWithMe+ project.

## 📋 О проекте
ExploreWithMe+ — это Spring Boot приложение для организации событий и поиска компании для участия в них. Пользователи могут создавать события, находить интересные мероприятия и управлять участием.

## 🏗️ Архитектура
Проект состоит из двух основных микросервисов:

### Основной сервис (Main Service)
- Управление событиями, пользователями, категориями
- Система комментариев к событиям
- API для администраторов и пользователей
- JPA-репозитории и бизнес-логика

### Сервис статистики (Stats Service)
- Сбор и анализ статистики просмотров
- HTTP-клиент для интеграции
- Хранение данных о посещениях

## 🚀 Особенности
- REST API с разделением доступа (публичный/закрытый/административный)
- Система комментариев к событиям
- Полная документация API через Postman-коллекции
- Docker-контейнеризация
- Интеграция между сервисами

## 🛠️ Технологии
- Java 17, Spring Boot
- Maven, Docker
- H2 Database (для разработки)
- Lombok, MapStruct
- REST API, JPA
